## 4. 结果口径

最终对外主结果以 Exp19 动态调频 paired/interleaved Benchmark 为准：文件 wall FPS 和 post-capture mean 中位改善分别为 3.638% 和 3.352%，相机 post-capture mean 中位改善 1.768%；V_Final 完成 54,000 帧稳定性测试。

以下边界在全部发布材料中保留：

1. `Host API Duration ≠ GPU Activity ≠ Critical Path`；
2. kernel 指标不能自动外推为 Runtime 或端到端收益；
3. Exp15 的 19.19% 与 Exp19 的最终配对结果属于不同阶段，不做累计拼接；
4. D2H 缩减不能单独解释全部后处理收益；
5. Serialized Engine 重复执行稳定，不等于同 ONNX 重新 Build 后 raw bitwise 一致；
6. 工程功能 `IMPLEMENTED` 或正确性 `VERIFIED`，不等于主线 `ACCEPTED`。

## 5. 能力与简历裁决

最终部署主线中的 ONNX、TensorRT FP16、C++ Runtime、CUDA preprocess、CUB stable compaction、视频/相机端到端和稳定性验证可以作为项目成果，但必须保留对应计时范围。

Plugin、Explicit Q/DQ、Mixed Precision、CUDA Graph、Pinned/Double Buffer 可以描述为已实现并验证的工程探索；由于性能 Gate 未通过，不得描述为最终加速方案。Full INT8 和 Exp03～Exp05 模型候选继续保留负向决策。

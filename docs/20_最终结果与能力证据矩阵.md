```text

→ 静态 FP32 ONNX
→ Jetson TensorRT FP16 Engine
→ TensorRT 10.3 C++ Runtime
→ CUDA fused preprocess
→ GPU decode/filter + CUB stable compaction
→ CPU inverse-letterbox + class-aware NMS
→ 文件 / IMX219
```

## 3. 已采用部署优化

| 项目 | 基线 | 最终/候选 | 变化 | Scope |
|---|---:|---:|---:|---|
| CUDA preprocess | CPU 2.2821 ms | kernel 0.2008 ms | −91.20% | Exp10 kernel-only |
| 后处理D2H | 235,200 B/frame | 263.84 B/frame | −99.888% | Exp15/Exp19文件输入 |
| Exp15文件 wall FPS | 60.270 | 71.838 | +19.19% | 当日三轮验收；动态E2E |
| Exp19文件 wall FPS | V0配对 | V_Final配对 | 中位+3.638%，2/3有利 | 最终动态paired/interleaved |
| Exp19文件 post-capture mean | V0配对 | V_Final配对 | 中位+3.352%，3/3有利 | 最终动态paired/interleaved |
| Exp19相机 post-capture mean | V0配对 | V_Final配对 | 中位+1.768%，3/3有利 | 30 FPS input-rate-bound |

Exp15与Exp19数字来自不同实验阶段和配对编排，不能拼成累计收益；最终对外优先报告Exp19。D2H缩减也不能
单独解释全部Runtime收益，Postprocess Gain Attribution Gate已证明GPU decode与压缩传输均有局部贡献，
但动态调频和顺序噪声使精确分摊不可识别。

## 5. 关键负向实验

| 候选 | 已完成证据 | 最终决策 | 原因 |
|---|---|---|---|
| YOLO11n-P2 | 训练与独立评估 | REJECTED | 精度/复杂度综合门槛未通过 |
| 重参数化、Attention/Focal | 公平训练消融 | REJECTED | 未替换baseline |
| implicit INT8 | Engine、219图精度、性能 | REJECTED | tiny+small recall 0.7902→0.4895 |
| Double Buffer | 正确性、时间线、三轮E2E | REJECTED | 局部重叠但P95显著退化 |
| IPluginV3 | Plugin/Registry/GraphSurgeon/独立进程与语义Gate | REJECTED | 系统性能无稳定收益 |
| Explicit QDQ/Mixed | 机制审计、219图、GPU-only配对 | REJECTED | 精度恢复但性能慢9.49%～40.57% |
| CUDA Graph | 候选轨迹一致、节点级Nsight、E2E配对 | REJECTED | launch/gap下降但E2E仅1/3有利 |

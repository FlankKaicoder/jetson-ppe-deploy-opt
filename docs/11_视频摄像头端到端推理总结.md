## 冻结主线

```text
GStreamer 文件视频 / IMX219
→ BGR 帧
→ CUDA 融合 letterbox + RGB + normalize + NCHW
→ Exp07 FP16 TensorRT Engine
→ YOLO11 解码 + 反 letterbox + class-aware NMS
→ 逐帧检测记录与阶段延迟分布
```

主线 Engine SHA256：

```text
88dcc29d2c66b77bdf5b3ac90f327f793516365d5967b51155987a5b736c0a83
```

冻结阈值为 `conf=0.25`、NMS IoU `0.70`；文件输入不丢帧，实时摄像头采用单帧
`appsink` 队列并丢弃过期帧。Exp11 只验收完整功能链路与结果合法性；综合性能、
功耗、温度和长期稳定性由 Exp12 单独验收。
